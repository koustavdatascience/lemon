Lemon

A user-controlled browser AI agent that reads, understands, and acts on web pages — with your approval on every step.

View on GitHub Quick Start

What Lemon does

📄 Summarise

TL;DR + key points for articles and YouTube videos. Clickable chapter timestamps.

💬 Page Chat

Ask questions answered only from the current page. No hallucination.

🔍 Find It

Describe an element in plain English. Lemon highlights it on the page.

🤖 Agent Loop

Multi-step tasks with Approve / Skip / Stop on every action.

👤 Profile Memory

Save your details. The agent auto-suggests them on forms.

⚡ Skills

Save reusable prompt recipes. Run with one click. Export as JSON.

Install in 4 steps

  1. Clone the repo and run npm install && npm run build
  2. Open chrome://extensions/ and enable Developer mode
  3. Click Load unpacked and select the dist/ folder
  4. Open the side panel, go to Settings, and add your free Gemini API key

Privacy first

✅ All data stays on your device in chrome.storage.local

✅ API keys are never logged, synced, or exported

✅ Lemon refuses to act on banking, payment, or crypto pages

✅ Password, OTP, and card fields are never filled by the agent

✅ Webmail, medical, and government portal pages are never sent to AI

✅ No DOM action runs without your explicit approval
